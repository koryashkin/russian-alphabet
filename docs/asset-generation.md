# Иллюстрации и единый стиль

Это семейный pet project для ребёнка автора. Приложение помогает знакомиться с русскими буквами, словами, звуками и письмом в коротких занятиях. Изображения не являются готовой учебной истиной: каждое значение, произношение и соответствие картинки слову проверяет взрослый перед публикацией.

## Как создаются изображения

Мы генерируем только предметную иллюстрацию: один объект на светлом фоне, без букв, подписей, цифр, логотипов и водяных знаков. Буква не встраивается в растровую картинку. В приложении она выводится отдельным HTML/SVG-слоем, поэтому:

- форма, размер и регистр буквы контролируются кодом;
- генератор не может случайно нарисовать неправильную букву;
- один предмет можно использовать с несколькими заданиями и буквами;
- замена изображения не меняет траекторию письма и текст.

Для текущего набора используется flat gouache children's-book стиль: тёплый почти белый фон, спокойные цвета, простой силуэт, один центральный объект, мягкая фактура кисти и много свободного места. Каждое слово генерируется отдельным изображением, затем уменьшается до 720 × 720 и сохраняется в WebP для быстрой загрузки на телефоне. В репозитории находятся 99 конечных файлов в `public/assets/words/`; исходные PNG остаются вне приложения.

## Правило prompt-а

Каждый запрос должен явно содержать: предмет и его точное значение, один объект, фронтальный или простой боковой ракурс, светлый фон, единый flat gouache стиль и запрет на любой текст. Для неоднозначных слов добавляется отрицательное уточнение: «лук — овощ, не оружие», «эхо — звуковые волны в пейзаже, без слов», «яма — углубление в земле, не дом».

После генерации проверяем смысл предмета, отсутствие текста, отсутствие лишних объектов, читаемость на iPad и совпадение с русским словом. Не принимаем изображение автоматически только потому, что оно красиво.

## Манифест

Имя файла состоит из Unicode code point буквы и номера слова в карточке от 0 до 2. Например, `42f-0.webp` — «яблоко», `42f-1.webp` — «яма», `42f-2.webp` — «мяч» в карточке буквы Я. Этот способ сохраняет точное соответствие и не зависит от транслитерации. В будущем в `content/assets.json` нужно хранить статус `generated`, `needs-review` или `approved`, размер, SHA-256, prompt ID и дату проверки.

## Следующий пакет

Сейчас сгенерированы 99 предметных иллюстраций: по три слова для каждой из 33 букв. Нажатие на слово меняет картинку и запускает его произношение. Для полного учебного пакета понадобятся альтернативные изображения для переноса, сцены мини-историй и изображения действий. Их нужно создавать тем же prompt-правилом и проверять отдельной записью взрослого.
